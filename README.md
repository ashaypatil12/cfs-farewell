# Thank You, CFS 💛

A colorful, interactive farewell page created for my last working day at CFS —
featuring personal thank-you cards for the colleagues who made the journey special.

## ✨ Features
- Animated gradient hero section with a confetti "Celebrate" button
- Interactive colleague cards (click to reveal a personal note)
- Live search to quickly find a name
- Fully responsive, no build step, no dependencies — just static HTML/CSS/JS

## 🚀 View it live
Once GitHub Pages is enabled for this repo (Settings → Pages → Deploy from branch → `main` → `/root`),
your site will be live at:

```
https://<your-github-username>.github.io/<repo-name>/
```

## 🛠 Files
- `index.html` — page structure & styles
- `data.js` — colleague names, roles, and personal messages (edit this to add/update people)
- `app.js` — card rendering, modal, search, and confetti logic

## ✏️ Before sharing
- Update the last working day date in `index.html` (search for `lastDay`)
- Update your personal email / LinkedIn link in the footer section of `index.html`
- Feel free to add or edit colleagues in `data.js`
